# Реализация хеш-таблицы

## Общее описание
Эта программа реализует хеш-таблицу с использованием метода списков для разрешения коллизий. Шаблонный класс `Set` позволяет хранить пары "ключ-значение" для любых типов данных.

## Основные возможности
- **Шаблонный класс**: Поддерживает любые типы данных для значений (ключи всегда string)
- **Динамическое расширение**: Автоматически увеличивает размер при коэффициенте заполнения > 4
- **Базовые операции**:
  - Добавление и обновление пар
  - Поиск по ключу
  - Удаление по ключу
  - Проверка наличия ключа
- **Обработка коллизий**: Метод списков
## Ограничения
- Ключи должны быть строками
- Хеш-функция может давать неравномерное распределение
